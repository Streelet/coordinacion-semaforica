# Escenarios

Guardar un JSON por escenario cuando se definan los parámetros.

Incluir: identificador, unidades, demanda, geometría y almacenamiento, tiempos semafóricos, coordinación, ubicación/duración/severidad del bloqueo, horizonte y semillas.

La comparación cambia la coordinación y conserva las demás condiciones. Aún no hay valores calibrados.
