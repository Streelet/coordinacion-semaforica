Figura 28 · ¿Son normales las llegadas? (gráfico de probabilidad normal + Anderson-Darling)¶

Idea. Si los datos fueran normales, al ordenarlos y graficarlos contra los cuantiles de una normal formarían una línea recta.

Prueba de Anderson-Darling, programada a mano. Medimos qué tanto se aleja la distribución acumulada de los datos de la normal, dando más peso a las colas:

$$A^2 = -n - \frac{1}{n}\sum_{i=1}^{n}(2i-1)\left[\ln F(z_{(i)}) + \ln\big(1-F(z_{(n+1-i)})\big)\right]$$

con $z$ estandarizado con la media y la desviación de la muestra y $F$ la acumulada normal. Como estimamos esos dos parámetros, se corrige: $A^{2*} = A^2(1 + 0.75/n + 2.25/n^2)$, y el valor p se aproxima con las fórmulas de D'Agostino y Stephens (1986). Valor p pequeño (< 0.05) ⇒ rechazamos la normalidad.

Comparamos la base completa contra un grupo homogéneo: Séptima, día laborable, 17 h (4 cuartos de hora × días laborables con esa hora).

In [9]:
def anderson_darling(x):
    x = np.sort(np.asarray(x, float)); n = len(x)
    z = (x - x.mean()) / x.std(ddof=1)
    F = np.clip(stats.norm.cdf(z), 1e-12, 1 - 1e-12)
    i = np.arange(1, n + 1)
    A2 = -n - np.mean((2*i - 1) * (np.log(F) + np.log(1 - F[::-1])))
    A = A2 * (1 + 0.75/n + 2.25/n**2)
    if A >= 0.6:   p = np.exp(1.2937 - 5.709*A + 0.0186*A**2)
    elif A >= 0.34: p = np.exp(0.9177 - 4.279*A - 1.38*A**2)
    elif A >= 0.2:  p = 1 - np.exp(-8.318 + 42.796*A - 59.938*A**2)
    else:           p = 1 - np.exp(-13.436 + 101.14*A - 223.73*A**2)
    return A, p

Lectura. La base completa se curva lejos de la recta y el valor p es prácticamente 0: no es normal porque mezcla accesos y horas. Dentro del grupo homogéneo los puntos siguen la recta y el valor p es alto: no rechazamos la normalidad. Tiene sentido, porque una Poisson con media grande (≈ 300) se parece mucho a una normal. Con solo 16 datos la prueba tiene poca potencia; “no rechazar” no es lo mismo que “demostrar”.

Figura 29 · Tiempo entre llegadas¶

Si las llegadas siguen un proceso de Poisson, el tiempo entre dos carros consecutivos es exponencial: muchos huecos cortos y pocos largos, con coeficiente de variación (CV = desviación / media) cercano a 1. Para que la tasa sea casi constante, usamos el mismo grupo homogéneo de la figura anterior y medimos los huecos dentro de cada intervalo.

Conclusiones¶

  1. Estructura: 19 variables, sin nulos, tipos correctos y relación 1:N consistente.
  2. Forma: las distribuciones globales no son normales porque mezclan accesos y horas; dentro de un grupo homogéneo las llegadas no rechazan la normalidad.
  3. Proceso de llegadas: los tiempos entre llegadas son exponenciales (CV ≈ 1): es un proceso de Poisson, como requiere SimPy.
  4. Factores: la lluvia fuerte y el evento MSG dejan una huella visible; la lluvia ligera es demasiado pequeña y escasa para distinguirse.
  5. Recordatorio: todo lo anterior valida el generador, no el tráfico real.
