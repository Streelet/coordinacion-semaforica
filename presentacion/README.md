# Presentación

Material para exponer el proyecto. Solo se guardan aquí conceptos y resultados que se puedan presentar.

## Qué hay

| Archivo | Para qué sirve |
|---|---|
| [`resultados/GUION_Y_CAPTURAS.md`](resultados/GUION_Y_CAPTURAS.md) | **Instrucciones para armar y exponer la presentación**: reglas de diseño, texto de cada diapositiva, guion oral, tiempos y fuentes. Léelo antes de modificar las diapositivas. |
| `resultados/presentacion_resultados.pptx` | PowerPoint editable de 10 diapositivas + 2 de respaldo, armado según el guion. Las notas del presentador contienen el guion oral, el tiempo y la fuente de cada lámina. |
| `resultados/presentacion_resultados.pdf` | Copia en PDF de respaldo. Regenerarla después de editar el PowerPoint. |
| `resultados/materiales/` | Gráficas y CSV del experimento (fuente de las tablas). |
| `resultados/capturas/` | Capturas de la maqueta 3D (una corrida ilustrativa, no promedios). |
| `01_conceptos_basicos.md`, `02_red_y_accesos.*`, `03_pregunta_investigacion.md` | Conceptos, red estudiada y pregunta de investigación. |

## Antes de presentar

1. Completar en la portada los integrantes, grupo y fecha (está marcado entre corchetes).
2. Ensayar con las notas del presentador: unos 10 minutos para las 10 diapositivas; las de respaldo solo si hay preguntas.
3. Si se cambia una cifra, tomarla de `resultados/materiales/resumen.csv` o `sensibilidad.csv` y conservar unidades y decimales.
4. Mantener A azul, B naranja y C verde, siempre con su letra.
5. Guardar de nuevo el PDF (Archivo → Exportar → PDF).

Reglas que no se negocian (detalle en el guion): la demanda es sintética, las capturas son una corrida con posiciones reconstruidas, y no se debe afirmar que C elimina la congestión ni que B siempre reduce la propagación.
